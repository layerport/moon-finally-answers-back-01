Entry for the [make.fun bounty "The Moon Finally Answers Back"](https://make.fun/bounty/u-mang-the-moon-finally-answers-back-781a7ec1).

One line the Moon says back to everyone who has ever stared up at it — an answer to the wishes, the howls, and the late-night promises:

> You keep promising me the moon. I AM the moon. I never got the memo, the flowers, or the follow-through.

## How it works

`main.py` (Python 3.13, standard library only, no network, fully deterministic) writes that single line to `/output/entry.txt`.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
